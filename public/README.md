# LifeOS Public Privacy Policy & Google Play Compliance Site

This folder contains the ready-to-deploy static website for **LifeOS** to satisfy:
1. **Google Play Store Mandatory Privacy Policy URL** (Play Console -> App Content -> Privacy Policy).
2. **Google Play 2024+ Account Deletion Web Request URL** (Play Console -> App Content -> Data Safety -> Account Deletion URL).
3. **Digital Personal Data Protection (DPDP) Act 2023** statutory disclosures & Grievance Redressal Officer contact.

---

## 🚀 How to Host for Free on GitHub Pages (2 Minutes)

1. Push this repository to GitHub (or create a new repo `lifeos-privacy`).
2. Go to your GitHub repository -> **Settings** -> **Pages** (in the left sidebar).
3. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`.
   - **Branch**: Select `main` (or `master`) and set the folder to `/docs`.
   - Click **Save**.
4. Within 60 seconds, GitHub will give you a live URL:
   `https://<your-username>.github.io/<repo-name>/`

---

## 📋 URLs to paste in Google Play Console

Once GitHub Pages is live, copy-paste these URLs:

1. **Privacy Policy URL**:
   `https://<your-username>.github.io/<repo-name>/#privacy`
   *(or simply `https://<your-username>.github.io/<repo-name>/`)*

2. **Account Deletion Web Request URL**:
   `https://<your-username>.github.io/<repo-name>/#deletion`

## 🛡️ Features Included in this Website:
- **Branded Design**: Matches LifeOS's Electric Cyan & Navy Blue visual theme with the official logo.
- **DPDP Act 2023 & GDPR Disclosures**: Highlights user rights under Sections 11, 12, 13, and 14.
- **Local-First Architecture Transparency**: Explains how data stays securely on device hardware.
- **Interactive Deletion Form**: Validates the user email and generates a pre-filled statutory deletion request email to `support@lifeos.in`.
- **Data Portability Guidance**: Instructions for users on how to export tasks, CRM leads, and invoices into JSON and CSV from within the app.
